
# Deadlock Hero Performance Analytics

## Business Problem
Game balance teams need reliable hero performance
statistics to identify patterns worth investigating.

## Project Objective
Develop a reproducible analytics pipeline and
interactive dashboard using Deadlock API data.

## Research Questions
1. Which heroes have the highest observed win rates?
2. How do hero pick rates relate to win rates?
3. How does sample size affect interpretation?

## Target Audience
Game analysts, balance designers and players.

## Project Scope
- Game mode: Normal
- Data: Community API hero statistics
- Analysis: Win rates, pick rates and match counts
- Output: Interactive Streamlit dashboard

## Success Criteria
- Data successfully retrieved from a real API
- Validated hero statistics
- At least three interactive visualisations
- Automated tests for key calculations
- Public GitHub repository at project completion
- Reproducible and documented methodology

## Limitations
API coverage may be incomplete.
Observed associations do not prove causality.
Hero performance is influenced by player skill,
team composition, patches and matchmaking.
